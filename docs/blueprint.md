# **App Name**: PulseWell

## Core Features:

- Daily Check-in: Collect user data on mood, energy, and sleep through a simple, quick form.
- Personalized Recommendations: Generate daily wellness recommendations based on user data, tailored to improve their well-being, acting as a tool.
- Motivational Messages: Provide short, empathetic, and motivational messages to encourage users, varying based on their check-in data.
- Activity Suggestions: Suggest brief activities (breathing, stretching, journaling) that align with the user's needs and data, acting as a tool.
- Data Visualization: Present user's data (mood, energy, sleep) visually over time to track progress.
- User Profile: Allow users to view/update personal info and wellness goals.

## Style Guidelines:

- Primary color: Soft lavender (#D1C4E9) for a calming and supportive feel.
- Background color: Light off-white (#F5F5F5) to provide a gentle and clean backdrop.
- Accent color: Pale green (#A5D6A7) to highlight positive actions and CTAs.
- Font: 'PT Sans', a humanist sans-serif font for clear and friendly readability in both headlines and body text.
- Use soft, rounded icons to represent mood, energy, and sleep. Make sure they're easily understandable at a glance.
- Keep the layout clean and straightforward, with an emphasis on whitespace to reduce visual clutter.
- Incorporate subtle animations when displaying motivational messages or updating charts to provide delight.
